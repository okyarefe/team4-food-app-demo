# Team 4 - Food ordering app

Course project for Software Project. A small food ordering app:
menu, cart, orders, payment, restaurants, reviews and delivery.

## Run

Backend: `cd backend && pip install -r requirements.txt && flask --app app run --debug`

Frontend: `cd frontend && npm install && npm run dev`

## Tests

Run `pytest` in the backend folder.

## API

- `/api/auth`: auth endpoints

- `/api/menu`: menu endpoints

- `/api/cart`: cart endpoints

- `/api/orders`: orders endpoints

- `/api/restaurants`: restaurants endpoints
